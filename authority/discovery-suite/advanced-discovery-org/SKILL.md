## FMLG Firm-Wide Conventions (apply to every run of this skill)

These six conventions govern all FMLG skills and override any narrower instruction
below that conflicts with them.

1. **Environment-flexible.** Complete the task in the environment you are already in
   — chat, Desktop, or Cowork. If a different environment would be materially better,
   say so in one line and keep working. Never block, never redirect, never hand off
   instead of doing the work.
2. **Identity over lanes.** Staff assignments in this skill are defaults, not gates.
   Anyone may run any skill. **Attorneys self-approve** — if the person running this
   skill is Naz or Leisa, they *are* the approving attorney. Never tell an attorney to
   route their own work to an attorney for approval. Approval gates mean an approving-
   attorney action is recorded, not that the user must go find someone.
3. **Just run it.** Prerequisite stages are soft checks, never hard gates. Pause only
   for a physically necessary input, and ask for that specific item by name — never
   "complete Stage X first."
4. **Read files first.** Search the entire matter file — including misnamed and
   misfoldered documents — before declaring anything missing. If the file is
   disorganized, offer a file-organizer cleanup rather than reporting a gap.
5. **Transcripts preferred, never required.** A typed memo or rough notes always
   suffice as input.
6. **Write to the command center.** Every stage completion, deadline, lifecycle move,
   and attorney flag is written to the matter's command center before the run ends.

# FMLG Advanced Discovery Assessor & Drafter

Assess whether advanced discovery is needed, identify what to send and why, and draft
all discovery instruments and enforcement work product using Florida family law rules
and FMLG's practice standards.

---

## INTAKE — REQUIRED BEFORE ANY DRAFTING

If any of the following are missing, ask before proceeding:

1. Case type (dissolution / paternity / modification / enforcement / post-judgment)
2. Issues in dispute (alimony / ED / child support / parenting / dissipation / hidden income / business valuation)
3. Mandatory disclosure status — served? timely? complete? what's missing?
4. Advanced discovery already served and what has been produced
5. Specific concern or suspicion driving the request
6. Case posture (pre-temp hearing / pre-mediation / pre-trial / enforcement)
7. Party or nonparty source for the records needed
8. Relevant date range

Do not draft without knowing the issues.

---

## RULE 1 — MANDATORY DISCLOSURE FIRST

Separate mandatory disclosure from case-specific discovery. Always.

Rule 12.285: automatic disclosure within **45 days** of service. Continuing duty to supplement when prior information becomes inaccurate. Objections must be served at least **5 days before** the due date or deemed waived.

| Problem | Correct Move |
|---|---|
| Not served at all | Deficiency letter → motion to compel |
| Served but incomplete | Item-by-item deficiency letter keyed to Rule 12.285 |
| FA inconsistent with other records | Advanced discovery to expose the gap |
| Suspiciously thin production | Advanced discovery + targeted subpoenas |

→ `references/rule-12-285-checklist.md` — item checklist and red flags
→ `references/deficiency-letter-template.md` — MD and advanced discovery deficiency letters

## ISSUE → RECORDS → TOOL MAP

**Hidden/underreported income**: Bank statements (personal + business), QuickBooks, 1099s, Schedule C, corporate returns, credit cards. RFP (party) + interrogatories + subpoenas to banks/accountants/payroll.

**Equitable distribution**: Deeds, investment/retirement statements, vehicle titles, business records, transfer records. RFP (party) + subpoenas to financial institutions.

**Dissipation**: Specific accounts + specific date range from breakdown + cash withdrawals, crypto, transfers. RFP keyed to those accounts + RFAs to pin breakdown date + interrogatories on withdrawals.

**Business valuation**: Corporate returns (3–5 yrs), P&L, QuickBooks, owner compensation, operating/partnership agreements. RFP (party) + subpoena if separate entity.

**Alimony**: Income records + lifestyle records (credit cards, travel, clubs, home improvements). RFP + interrogatories on income sources.

**Parenting/time-sharing**: School, medical, OurFamilyWizard/TalkingParents exports, texts, extracurricular, childcare. RFP + subpoenas (school, pediatrician) + RFAs on specific incidents.

**Relocation**: Employment offer, housing contract, school enrollment, proposed schedule. RFP + interrogatories.

**Parental fitness**: DCF records, law enforcement, substance abuse, mental health. ⚠️ Mental health/substance records require court order or authorization — attorney must clear before service.

## SELECT THE RIGHT TOOL

| Goal | Tool | Rule |
|---|---|---|
| Documents from the other party | Request for Production | 12.350 |
| Sworn written answers | Interrogatories | 12.340 |
| Pin a fact / authenticate a document | Request for Admission | 12.370 |
| Documents from a nonparty (no deposition) | Rule 12.351 Subpoena | 12.351 |
| Question someone under oath | Deposition | 12.310 |
| Enforce mandatory disclosure | Deficiency letter → Motion to Compel | 12.285 + 12.380 |
| Enforce discovery failures | Motion to Compel + Sanctions | 12.380 |

**Rule 12.351 is the EXCLUSIVE procedure for nonparty document production without a deposition.** Notice to all parties required. → `references/rule-12-351-and-response-review.md`

**RFA deemed admission**: No response within 30 days = admitted by law. File to confirm, not to compel. → `references/interrogatories-rfa-template.md`

---

## DEADLINES

- RFP / Interrogatories: **30 days** from service (Rules 12.350, 12.340)
- RFAs: **30 days** — no response = **deemed admitted** (Rule 12.370)
- Mandatory disclosure: **45 days** from service of applicable petition (Rule 12.285)
- MD objections: **5 days before due date** or waived
- Email service: Fla. R. Jud. Admin. 2.516 — save tagged to Smokeball

---

## OBJECTION ANALYSIS

Reject immediately: "Overbroad" with no specificity. "Unduly burdensome" with no factual support. "Not reasonably calculated" (outdated standard). "Vague" followed by an actual answer. "Without waiving" when no non-objectionable portion was produced.

For each deficient response: what was requested → what was produced → what is missing → is the objection colorable → does narrowing solve it → meet-and-confer or motion.

→ `references/rule-12-351-and-response-review.md` — full response review framework
→ `references/motion-to-compel-template.md` — motion to compel and Rule 12.380 sanctions

## NEXT MOVE

- MD problem → deficiency letter; motion to compel if not cured
- Advanced discovery not yet served → draft and serve
- Discovery served, no response → confirm deadline; deficiency letter; motion to compel
- Responses deficient → objection analysis → deficiency letter → motion to compel
- RFAs unanswered → motion to confirm deemed admissions under Rule 12.370
- Prior order violated → Rule 12.380 sanctions motion

## AMBIENT STANDARD — FMLG PLEADING FORMAT & DRAFT-STATE RULES

`fmlg-pleading-standard` governs every court-bound document this skill produces.
Two rules, from the first keystroke:

1. **Format correctly immediately** — portrait, Times New Roman 12 black, single
   spacing 0pt before/after, left aligned, 1" margins, FMLG caption (court centered ·
   case/division right · parties left · rule line ending in `/` · title centered
   bold ALL CAPS), numbering I. → 1. → a. → i. continuous. No bullets, no dividers.
   There is no rough-format stage that gets fixed later.
2. **Drafts show their work, highlighted** — attorney notes 🟨, outstanding facts 🟨,
   alternative provisions 🟩 drafted in full. When unclear what the pleading should
   contain, present highlighted ALTERNATIVES — never assume and draft one version
   as if decided. Never strip flags at draft stage; only `fmlg-finalize-draft`
   strips, after the attorney resolves them.

## MANDATORY HANDOFF — PRE-FILING QC GATE

Any document this skill produces that will be **filed with a court, served on a
party, or sent outside the firm** goes to `fmlg-prefiling-qc` before it reaches
an attorney. This handoff is not optional and is not skippable for urgency.

```
THIS SKILL  →  fmlg-prefiling-qc  →  ATTORNEY SIGN-OFF  →  FILE / SERVE / SEND
```

- Do not present a draft as "ready for Naz" or "ready to file" until the gate has run.
- A **BLOCKED** verdict returns the draft here for correction. Fix and re-run the gate.
- A **CONDITIONAL** verdict goes to the attorney with the findings attached.
- Never resolve a flagged item by deleting the language to make the gate pass.

- After the gate clears, hand the document to `fmlg-finalize-draft` to produce the
  filing-ready Word file and PDF. That skill enforces portrait, Times New Roman 12,
  all black, single spacing, the FMLG caption layout, strips every internal artifact,
  and checks `fmlg-judicial-procedures` for the assigned judge before output.

**Approval behavior:** if the person in the session is an FMLG attorney (Leisa or
Naz), her instruction IS the sign-off — do not ask her to approve what she just
directed. If staff, every attorney-gated item routes to Naz or Leisa and waits.
